# томи

подарочный сайт: 3d-сердце, время вместе, карта маршрута и 100 причин.

открыть: `index.html` в браузере (работает и без интернета) или через github pages.

## что поменять без сборки
всё в `content.js`:
- `start` — дата начала отношений
- `trip` — страны маршрута и тексты к ним (порядок = порядок на карте)
- `reasons` — список причин, счётчик подстраивается сам

## пересборка (если меняешь код сердца, карты или html)
```
cd _build && npm i && npm run build
```
исходники в `_build/src`, карта строится из world-atlas скриптом `build-map.mjs`.
